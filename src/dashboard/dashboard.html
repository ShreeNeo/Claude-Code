💾 Data Management ▼

📊 Storage Information

All your data is stored locally in your browser using IndexedDB. No external servers involved.

  • ✓ Tracking sessions and manual entries
  • ✓ Employee profile and settings
  • ✓ Integration credentials (encrypted)
  • ✓ Custom categories and tags

☁️ Backup Recommendations

See Data Sync Guide for backup strategies:

  • Export timesheet weekly/monthly
  • Save CSV files to cloud storage (Google Drive, Dropbox)
  • Chrome Sync handles settings automatically

⚠️ Danger Zone

Clearing data will permanently delete all tracked sessions, stats, and manual entries. This action cannot be undone. Please export your data first!
