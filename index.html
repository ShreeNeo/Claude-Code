Get Started in Minutes

1

Clone the Repository

Get the source code from GitHub

git clone https://github.com/yourusername/neram.git
cd neram
2

Install Dependencies & Build

Set up the project and create the extension bundle

npm install
npm run build
3

Load in Browser

Open Chrome/Edge, go to chrome://extensions/, enable "Developer mode", click "Load unpacked", and select the dist folder.

4

Start Tracking!

Click the extension icon to see your dashboard. Configure your employee profile and start tracking your time automatically.
