HOW IT WORKS

Get. Set. Forget.

Three simple steps to automatic time tracking that runs in the background while you focus on your work.

1
GET

Install & Configure

Clone the repository, install dependencies, and build the extension in under 5 minutes. Load it in your browser and configure your employee profile for timesheet exports.

  • One-command installation with npm
  • Load unpacked extension in Chrome/Edge
  • Configure employee details for exports
  • Set tracking preferences and blocked domains
2
SET

Connect Your Tools

Optionally connect GitHub with a Personal Access Token and calendar with your own OAuth credentials. All integrations are completely free using the BYOC (Bring Your Own Credentials) approach.

  • GitHub integration with PAT (5-minute setup)
  • Google Calendar with your OAuth app
  • Microsoft Outlook with Azure AD app
  • Custom tags and categories for organization
3
FORGET

Browse & Track Automatically

That's it! Neram now runs silently in the background, automatically tracking your time across websites, GitHub activities, and calendar meetings. View insights anytime from the beautiful dashboard.

  • Automatic tracking with zero user interaction
  • Real-time sync across browser, GitHub, calendar
  • Smart idle detection and activity categorization
  • Export professional timesheets whenever needed
